# ЛР1. Воспроизводимый проект: Bike Sharing (вариант 1)

## Постановка задачи
Регрессия: предсказание числа аренд велосипедов за час (`cnt`) по погодным,
календарным и временным признакам. Источник — UCI Bike Sharing Dataset.

## Структура
- `src/` — этапы обработки и обучения;
- `notebooks/` — рабочий ноутбук Colab;
- `tests/` — автоматические проверки;
- `data/` — исходные и обработанные данные (содержимое управляется DVC);
- `models/` — обученная модель;
- `reports/` — метрики и данные для графика;
- `params.yaml` — параметры проекта;
- `dvc.yaml` — граф зависимостей.

## Воспроизведение
1. Установить зависимости из `uv.lock`.
2. Настроить секреты Colab и DVC remote.
3. Выполнить `dvc pull`.
4. Выполнить `dvc repro`.
5. Посмотреть `reports/metrics.json`.

## Версии данных
- `data-2011`: записи за 2011 год.
- `data-2012`: записи за 2011–2012 годы.

Для возврата к версии:
```bash
git checkout data-2011
dvc checkout
dvc repro
```

## Метрики
После выполнения пайплайна метрики находятся в `reports/metrics.json`.
